# 멘트 가이드 (용어집, 말투 규칙)

게임 안에 보이는 모든 글(버튼, 안내, 튜토리얼, 캐릭터 설명, 업적)의 기준이다. 새 멘트를 쓰거나 고칠 때 이 문서를 따른다. 규칙(수치, 판정)의 기준은 `game_design.md`이고, 이 문서는 **플레이어에게 보이는 말**만 다룬다.

## 1. 말투

| 자리 | 규칙 | 예 |
|---|---|---|
| 설명, 안내, 튜토리얼 | 해요체. 합니다체를 쓰지 않는다 | 씨앗이 2배 빨리 자라요 |
| 플레이어에게 시키는 말 | "~해 보세요". "~하세요", "~해 봐요"는 쓰지 않는다 | 족보를 완성해 보세요 |
| 버튼, 제목, 탭 | 명사 또는 "~하기". 문장부호 없음 | 다시 하기, 받기, 장착하기 |
| 상태 줄 (HUD 캐릭터 줄, 메시지 줄) | 짧은 명사구. 조사 생략, 구분은 " / " | 8수 / 6초, 피버 5스택! |
| 업적 조건 | 명사구. 횟수는 "N회", 개수는 "N개" | 한 판에 촉진 15회 |
| 확인 질문 | "~할까요?" | 정원사 캐릭터를 ◆ 80에 해금할까요? |

- 한 문장에 정보 하나. 한 칸에 두 문장까지. 길어지면 문장을 나눈다 (괄호 안에 설명을 쌓지 않는다).
- 플레이어는 "나/내"로 부른다 (내 주변, 내가 있던 칸). "플레이어", "유저", "당신"은 쓰지 않는다.
- 느낌표는 칭찬, 발동, 순간 강조에만, 한 칸에 하나. 물음표는 퍼즐 팁처럼 말을 거는 자리에.
- 짧은 안내(한두 문장)는 마지막 마침표를 찍지 않는다. 캐릭터 상세 설명처럼 여러 문장은 찍는다.
- **가운뎃점(·)을 쓰지 않는다.** 낱말을 늘어놓을 때는 쉼표나 "와/과"(흔들림, 파편), 나란한 값, 상태는 " / "(8수 / 6초, 5스택 750 / 10스택 2,750), 제목 뒤 내용은 띄어쓰기나 " / "(시계공 발동해 보기, 시계공 / 시간 정지).
- 줄표(—), "및", "~을 통해", "~할 수 있습니다", "을(를)"을 쓰지 않는다. 조사가 갈리면 문장을 바꿔 쓴다.
- 개발 용어, 한자어 대신 쉬운 말: 즉시 → 바로, 무작위 → 아무, 색 무관 → 색과 상관없이, 리필 → 씨앗이 자라요, 획득 → 얻어요/받아요, 취급 → 쳐요, 실행 → 움직여요.
- 수식은 보여 주지 않는다. 대표 값으로 보여 준다 (5스택 750 / 10스택 2,750).
- 숫자는 아라비아 숫자 + 단위를 붙여 쓴다 (4초, 2칸, 6발). 곱은 ×, 더하기는 +, 재화는 ● 코인, ◆ 다이아. 폰트에 없는 그림 문자(⚡ 등)는 쓰지 않는다 (웹에서 네모로 보인다). 천 단위 쉼표.
- 의성어(쿵, 쾅, 드르륵)와 말 거는 팁("조금 더 어려울걸요?")은 살린다. 게임의 목소리다.

## 2. 용어집

한 가지를 한 낱말로만 부른다. 오른쪽 말은 쓰지 않는다.

| 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 블록 | 판 위의 색 칸 | 블럭, 타일 |
| 씨앗 | 매치한 자리에 남아 블록으로 자라는 것 | 빈칸, 재생 중인 칸, 리필 |
| 매치 / 매치하다 | 내 위아래, 양옆 네 칸을 같은 색으로 맞춰 없애는 일 | 깨다(블록을), 부수다, 제거 |
| 터지다 | 능력으로 블록이 없어질 때 (폭파범) | — |
| 족보 | 맞출 색 순서 카드 | 레시피, 미션 |
| 캐릭터 족보 | 능력을 발동시키는 족보 | 고정 족보 |
| (족보 칸을) 채우다 / 차다 | 족보가 한 칸 나아감 | 올라가다, 진행되다, 전진 |
| (족보를) 완성하다 | 족보의 모든 칸을 채움 | 끝내다, 클리어 |
| 발동 | 캐릭터 족보를 완성해 능력이 켜짐 | 사용, 시전 |
| 족보형 / 상시형 | 캐릭터 족보로 발동 / 항상 켜짐 | 발동형(기획서 용어) |
| T 모양 | 한 칸만 들어가면 매치되는 같은 색 네 칸 | ㅗ (방향을 다 보여 줄 때만 ㅗ, ㅜ, ㅓ, ㅏ) |
| 코인 ● | 재화. 판 위의 것은 "코인 블록" | 금화(기획서, 코드 용어), 골드 |
| 다이아 ◆ | 재화 | 보석, 젬 |
| 선택권 | 등급 안에서 캐릭터를 골라 해금 | 해금권, 티켓 |
| 해금 | 캐릭터를 얻어 쓸 수 있게 됨 | 구매, 언락 |
| 열림 | 기능, 상점 등급이 쓸 수 있게 됨 | 개방, 해금(기능에) |
| 장착 | 판에 데려갈 캐릭터로 고름 | 선택, 착용 |
| 체험 | 없는 캐릭터로 해 보는 한 판 | 시험, 트라이얼 |
| 판 | 게임 한 번, 또는 블록이 깔린 곳 | 스테이지, 라운드(퍼즐 제목 제외), 보드 |
| 벽 | 판의 가장자리 바깥 | 경계 |
| 수 | 이동 한 번 (퍼즐 "3수", 묘수꾼 "8수") | 턴, 무브 |
| 스와이프 | 화면을 미는 조작 | 드래그, 스왑(자리 바꾸기는 "자리를 바꾸다") |
| 방향키 | 화면의 십자 버튼 조작 방식 | 패드 |
| 누르다 | 화면, 버튼을 한 번 누름 | 탭하다, 터치하다, 클릭 |
| 꾹 누르기 | 움직이지 않고 오래 누름 | 롱프레스 |
| 최고 기록 / 최고점 | 기록을 새로 세움 / 그 점수 | 하이스코어, 베스트 |
| 시간이 멈추다 | 남은 시간이 줄지 않음 | 시간 정지(상태 줄에서는 "정지" 가능) |
| 색 이름 | 노랑, 빨강, 파랑, 초록 | 옐로, 적색 등 |
| 등급 | 희귀, 영웅, 전설, 신화, 히든 | 레어, 에픽 등 |

- 캐릭터 이름, 능력 이름은 `game_design.md` 5.2장 표가 기준이다.
- `CharacterData.ability_description`은 5.2장 표의 "능력" 칸과 같아야 하는 규칙 요약이라 화면에 쓰지 않는다. 화면의 한 줄 설명(발동 배너, 뽑기 결과, 캐릭터 튜토리얼 소개)은 `CharacterData.summary`, 자세한 설명은 `detail_effect`.

## 3. 표로 한꺼번에 고치기

문구는 스크립트, 씬, 리소스에 흩어져 있다. `python3 tools/copy_table.py export copy.csv`로 전부 표 하나로 뽑아 `new` 칸만 채운 뒤 `python3 tools/copy_table.py apply copy.csv`로 반영한다. 그 뒤 단위 테스트를 돌린다.

## 4. 고칠 때 확인

1. 용어집의 "쓰지 않는 말"이 없는가.
2. 말투 표의 자리에 맞는 끝맺음인가.
3. 실제 규칙, 수치와 맞는가 (기획서, 능력 리소스).
4. 화면에서 줄이 넘치지 않는가 (설명 칸 두 줄, 버튼 한 줄).
