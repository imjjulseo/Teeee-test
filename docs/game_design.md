# 0. 한눈에 보는 게임 정의

**장르:** 1인 시간제 스코어어택 퍼즐 (3매치 낙하 연쇄도, 로그라이크도 아님)

**핵심 목표:** 제한시간 안에 플레이어 블록을 움직여 주변 4칸을 같은 색으로 맞춰 깨고(시간 획득), 화면 위 **족보**의 색 순서대로 깨서 족보를 완성해(점수 획득) 최고 점수를 노린다. 캐릭터마다 고정 족보와 능력이 있어 플레이 방식이 바뀐다.

**핵심 조작:** 1회 입력(스와이프 / 패드 / 방향키 / 옆 칸 탭) = 상하좌우 1칸 이동. 목적지 블록과 자리를 바꾼다. **이동과 판정은 즉시** 일어나고 애니메이션은 보여주기만 한다.

**핵심 판정:** 이동 직후 플레이어의 상·하·좌·우 4칸이 모두 판 안의 다 자란 블록이고 같은 색이면 4개가 깨진다. 깨면 **시간**을 얻고, 깬 색이 족보를 진행시킨다. 점수는 **족보를 완성할 때만** 얻는다.

> **Core Loop**
>
> 판 읽기 → 다음 족보 색·경로 결정 → 이동·교환 → 주변 4칸 정렬 → 매치(시간 획득) → 족보 진행·완성(점수) → 캐릭터 능력 발동 → 반복

**메타 루프:** 판 점수 → 경험치·코인 → 계정 레벨(보드 단계·보상) → 뽑기·상점·선택권으로 캐릭터 해금 → 새 캐릭터로 더 높은 점수 (8장)

**조상:** 퍼즐앤드래곤(끌며 교환), 컬러 타일(4방향 같은 색), 비주얼드 블리츠(매치로 시간 회복), 발라트로(족보)

**고유한 점:** 플레이어가 판 위의 한 칸이 되어 블록을 밀고 다닌다. 홍보와 캐릭터 설계의 중심.

**가장 큰 위험:** 계획 게임이 아니라 조작 속도 싸움이 되는 것. 판별 지표는 매치 1회당 이동 수 분포(1~4수에만 몰리면 순발력 게임, 8수 이상 꼬리가 살아 있으면 계획이 성립, 10.1장).

# 2. 보드와 오브젝트 명세

## 2.1 좌표와 판 크기

판은 N×N(기본 9), 좌표는 0 기반 (x, y). 플레이어가 1칸을 차지하므로 색 블록은 N²-1개다.

| **판** | **전체 칸** | **블록** | **4색일 때 색별** | **3색일 때 색별** |
|---|---|---|---|---|
| 9×9 | 81 | 80 | 20 | 27 · 27 · 26 |
| 7×7 | 49 | 48 | 12 | 16 |

색 수로 나누어떨어지지 않으면 앞 색부터 1개씩 더 많다 (블록 i번의 색 = i mod 색 수, 그 뒤 셔플).

## 2.2 셀(Cell) 상태

| **상태** | **설명** | **필수 데이터** |
|---|---|---|
| Player | 플레이어가 점유한 칸 | 좌표, 캐릭터 외형 |
| ColorBlock | 다 자란 색 블록 | 색 ID, (금화 남은 시간) |
| Seed | 깨진 자리에 심어진 씨앗. **다음 색은 정해져 있지만 보이지 않고 매치되지 않는다** | 다음 색, 단계(대기/자람), 남은 시간 |
| Empty | 규칙상 상태만 둔다. 일반 판에서는 생기지 않는다 | — |

- 씨앗은 블록처럼 플레이어와 자리를 바꾸며, 진행 상태를 유지한다.
- 그리드 데이터가 진실의 원천(Source of Truth)이다. 화면 위치로 판정하지 않는다.

## 2.3 초기 판 생성

1. N×N 그리드, 중앙을 플레이어로 예약한다.
2. 블록 수만큼 색 목록(i mod 색 수)을 만들어 보드 RNG로 셔플(Fisher-Yates)하고 순서대로 채운다.
3. 플레이어 주변 4칸이 매치 형태면, 위쪽 이웃 블록의 색을 플레이어와 맨해튼 거리 2 이상이면서 색이 다른 무작위 블록과 맞바꾼다. 매치 형태가 없어질 때까지(최대 50회) 반복한다 (E3).

# 4. 매치 판정과 블록 제거

## 4.1 매치 조건

플레이어 기준 상·하·좌·우 4칸이 모두 판 안의 **다 자란 블록**이고 색이 같으면 매치. 씨앗·Empty·다른 플레이어가 하나라도 있으면 실패. 대각선은 보지 않는다.

캐릭터 예외: 벽 타는 자(벽 쪽 1칸 빼고 3칸), 항해사(판 반대편과 이어짐), 뱀파이어 피의 시간(색 무관), 색약(두 색을 같은 색으로) — 5.2장.

## 4.2 매치 처리

1. 깨진 칸의 금화를 코인으로 얻는다 (4.4장).
2. 시간을 얻는다 (5장).
3. 깨진 칸마다 씨앗을 심는다. 색은 **분산 규칙**으로 정한다: 깬 색이 아닌 색들을 무작위 순서로 하나씩 먼저 쓰고, 칸이 남으면 깬 색, 그래도 남으면 판에서 가장 부족한 색. 그 뒤 칸 순서를 섞는다. 4칸 매치면 네 색이 하나씩 들어간다 (E6).
4. 깬 색으로 족보를 진행한다 (5.1장).

## 4.3 씨앗과 리필

- 씨앗은 **대기 → 자람 → 다 자란 블록** 순서로 바뀐다. 대기 동안은 작은 점, 자람 동안은 중앙에서 커진다.
- 리필 총시간 = 8초에서 판 경과 90초에 걸쳐 2초로 선형 감소 (그 뒤 2초). 대기 : 자람 = 3 : 5. 씨앗이 심어질 때 한 번 계산한다.
- 리필 시계는 일반 시계와 따로 흐르며, 능력이 빠르게(축제꾼 ×2, 뱀파이어 ×2.5) 하거나 멈춘다(사진사·마탄·제우스).
- 다 자라는 순간 매치 형태가 생겨도 판정하지 않는다. 다음 이동으로만 매치된다.
- 막힌 판(dead board)은 감지하지 않는다.

## 4.4 금화

| **항목** | **값** |
|---|---|
| 붙는 때 | 블록이 다 자라는 순간 10% 확률 (판 위 금화 3개 미만일 때만, 튜토리얼 제외) |
| 수명 | 15초 (리필 시계 기준), 마지막 4초 깜빡임 |
| 획득 | 금화 블록이 매치로 깨지면. 직전 금화로부터 4초 안이면 연속: 10 → 20 → 30 … |
| 정산 | 판 끝 코인 = ⌊점수 ÷ 100⌋ + 판에서 주운 금화 (8.4장) |

## 5.1 족보 시스템

- 일반 족보 3장, 길이는 슬롯 순서대로 **2 · 3 · 4칸 고정** (보드 단계 1~2는 2장: 2 · 3칸).
- 색은 무작위(중복 허용)이되, **첫 색은 판에 4개 이상** 있어야 하고 **다른 족보와 완전히 같으면 다시** 뽑는다(최대 40번 시도).
- 점수 = `100 × L(L−1)/2 × (1 + 0.25 × 반복 수)`, 반복 수 = 바로 앞 칸과 같은 색인 칸 수 (E7).

| **길이** | **반복 0** | **1** | **2** | **3** |
|---|---|---|---|---|
| 2칸 | 100 | 125 | — | — |
| 3칸 | 300 | 375 | 450 | — |
| 4칸 | 600 | 750 | 900 | 1,050 |
| 5칸 (건축가) | 1,000 | 1,250 | 1,500 | 1,750 |

- 매치 1회 = 1칸 (B8). 다음 색과 같으면 진행, 다른 색은 무시(진행 유지, B6).
- 세 족보는 독립적으로 진행하고, 한 번에 여러 장이 완성되면 합산 (B7).
- 완성된 족보는 같은 자리에 같은 길이로 새로 나온다 (B10).
- 표시: 카드마다 색 점과 문양, 지난 칸은 흐리게, 다음 칸 강조. 카드 배경은 다음 색으로 은은하게 (D9).

## 5.2 캐릭터와 능력

**공통 규칙**

- 캐릭터마다 플레이어 외형 색이 다르다. **발동형**은 고정 족보(캐릭터 족보)를 가지며, 일반 족보와 같은 규칙으로 진행해 완성하면 능력이 발동하고 처음부터 반복한다. **상시형**은 족보 없이 항상 켜져 있다.
- 캐릭터 족보는 일반 족보 아래 캐릭터 줄 오른쪽에 표시하고, 상태(남은 초·스택·남은 수)는 같은 줄 가운데에 표시한다 (7.1장, E35).
- 능력 효과가 켜져 있는 동안에도 캐릭터 족보는 평소처럼 진행되고, 완성하면 다시 발동한다 (HTML 규칙, E11).
- 수선사 끈이 있는 동안, 마탄 사격·수선사 매치로 깬 색은 캐릭터 족보를 진행하지 않는다.
- 지속 효과가 켜져 있으면 화면 배경을 그 효과 색으로 은은하게 칠하고(남은 시간이 가장 짧은 효과), 끝나기 3초 전부터 점점 빠르게(2→8Hz) 깜빡인다.
- 능력으로 블록이 바뀌거나 즉시 자라도 자동 판정하지 않는다(예지안 발동 제외).
- 색 문자: A 노랑 · B 빨강 · C 파랑 · D 초록.

# 7. UI/UX와 피드백

## 7.1 플레이 화면

- 위쪽: 남은 시간(소수 1자리), 점수(부드럽게 차오름), 판에서 주운 코인, 일시정지 버튼. 그 아래 시간 막대.

## 8.2 계정 레벨과 보드 단계

- 경험치 = 판마다 500 + 0.25 × 점수 (내림) **(임시, E26)**. 결과까지 간 판만, 판을 넘어 누적. 메뉴로 나간 판·튜토리얼·체험 판은 없음.
- 필요 경험치: Lv20 미만 `500 + 100 × (Lv − 1)`, Lv20부터 `2400 + 200 × (Lv − 20) + 10 × (Lv − 20)²` **(임시, E26)**. 레벨 제한 없음. Lv20까지를 초보자 구간으로 본다.
- 레벨업 보상: 코인 100 + 다이아 10 (매 레벨 같음) **(임시)**. 자동으로 주지 않고 레벨 보상 화면에서 눌러서 받는다 (마일스톤 선택권 포함, E36).

| 발동형 / 상시형 | 캐릭터 족보로 발동하는 능력 / 항상 켜진 능력 |
| 매치 시간 | 매치할 때 얻는 시간. 매치 수가 늘수록 줄어듦 |
| 리필 시계 | 씨앗 성장·금화 수명에 쓰는 시계. 능력으로 빨라지거나 멈춤 |
| 보드 단계 | 계정 레벨 1~3에 따라 바뀌는 판 규칙(색 수·족보 수·시간) |
| 선택권 | 등급을 골라 그 등급 캐릭터 하나를 해금하는 권리 (구 해금권, E23) |
| 조작 잠금 연출 | 연쇄 폭파·낙뢰·사진 실행처럼 입력을 받지 않고 시간이 멈추는 연출 |
| Swap / Match / Resolve | 교환 / 매치 / 이동 뒤 판정·제거·족보 반영 처리 |
| RNG / Seed / Deterministic | 난수 / 재현용 초기값 / 같은 입력·seed면 같은 결과 |
| Source of Truth | 실제 게임 상태를 결정하는 기준 데이터(논리 그리드) |
| Softlock / Dead Board | 사실상 진행 불가 상태 / 매치가 어려운 판 (감지하지 않음) |

# 12. 개발 완료 판정용 QA 체크리스트

| **테스트 항목** | **Acceptance Criteria** |
|---|---|
| 판 생성 | N×N, 플레이어 중앙, 색 개수가 2.1장 표와 같고, 플레이어 주변에 매치 형태가 없다 |
| 랜덤 배치 | 여러 seed에서 배치는 다르지만 색 개수는 같다. 같은 seed는 같은 판 |
| 기본 이동 | 입력 1번 = 1칸, 즉시 그리드 반영 |
| 교환 | 블록·씨앗과 정확히 교환, 씨앗 상태 유지 |
| 경계 | 판 밖으로 나가지 않는다 (거울·항해사 제외) |
| 매치 성공·실패 | 4칸 같은 색 다 자란 블록만. 3개·대각선·씨앗 포함은 실패 |
| 즉시 판정 | 이동한 같은 처리 안에서 매치·시간·족보가 반영된다 |
| 매치 시간 | n번째 매치에 max(0.8, 2.5 − 0.08(n−1))초 |
| 리필 | 씨앗이 대기 → 자람 → 블록, 총시간이 경과 시간에 따라 8→2초, 4칸 매치는 네 색 하나씩 |
| 족보 | 2·3·4칸, 점수표와 같음, 첫 색 4개 이상, 중복 없음, 동시 완성 합산 |
| 시작·종료 | 첫 이동 전 시계 정지, 0초 즉시 종료, 부활 1번 |
| 금화 | 확률·최대 수·수명·연속 보너스·판 끝 정산 |
| 연속 입력 | 빠른 연타·홀드 반복에서도 위치와 그리드가 어긋나지 않는다 |
| 재시작 | 이전 점수·시간·판·능력 상태가 남지 않는다 |
| 프레임 독립성 | 30/60/120fps에서 같은 입력이면 같은 결과 |
| 캐릭터 | 5.2장 수치대로 발동·지속·종료, 판을 바꿔도 상태가 남지 않는다 (자동 플레이로 불변식 검사) |
| 진행·재화 | 경험치·레벨업 보상·뽑기 확률·중복 선택권·합성·상점 가격이 8장과 같다 |
| 저장 | 진행·재화·설정이 재실행 후 유지된다 |
| 화면 비율 | 9:16 · 19.5:9 · 20:9 · 3:4와 노치에서 겹치거나 가려지지 않는다 |
